Что это за сайт

Информационная страница сервиса в разработке

PickForge — независимый проект. Эта страница описывает сервис, то, как мы работаем с партнёрскими ссылками, и кто за ним стоит. Это не магазин, и мы ничего не продаём.

Ссылки Amazon.com на этой странице собираются в браузере: полный адрес amazon.com с идентификатором Associates pickforge-20. Партнёрскую ссылку AliExpress создаёт только API AliExpress Portals на нашем сервере. Эта страница не вызывает этот API и не подделывает ссылку.

Покупка проходит на сайте магазина, где видна цена. Мы не принимаем заказы, не храним товары и не даём финансовых или медицинских советов.

PickForge участвует в Amazon Associates и в партнёрской программе AliExpress (Portals). Если вы купите товар по ссылке, которую мы пометили, мы можем получить комиссию. Доплаты нет.

Ссылки Amazon.com на этой странице — полный адрес amazon.com, включая идентификатор Associates pickforge-20. Мы не прячем его за коротким адресом. Amazon не спонсирует и не поддерживает PickForge. Ниже — обязательная формулировка программы на английском.

Конфиденциальность

Эта страница статическая: без регистрации, формы обратной связи и рассылки.

Сборщик ссылок работает в вашем браузере. Адрес товара или слова поиска не отправляются в PickForge. Переход открывает Amazon или, если ссылку выдал наш сервер, AliExpress. Эти магазины могут ставить свои cookie.

Инструмент ассистента, когда он будет опубликован, получает поисковый запрос только чтобы вернуть результат. Мы не продаём персональные данные. Хостинг может записывать обычные данные доступа (IP-адрес, user agent).

Вопросы

Что такое PickForge?

Независимый проект: инструмент, с помощью которого ИИ-ассистенты ищут товары и возвращают партнёрские ссылки. Сервис в разработке.

Вы продаёте товары?

Нет. Покупки совершаются на сайтах продавцов. Мы не ведём оформление заказов, не храним товары и не ведём аккаунты покупателей.

Влияют ли комиссии на результаты?

Нет. Комиссия не меняет порядок результатов поиска.

Помечены ли партнёрские ссылки?

Да. Ссылка, которая может принести комиссию, помечена как партнёрская.

Можно ли собрать ссылку Amazon на этой странице?

Да. Сборщик возвращает полный адрес amazon.com с tag=pickforge-20. Откройте его с этой страницы. Цену страница не показывает.

Можно ли собрать ссылку AliExpress на этой странице?

Вставьте URL товара AliExpress — сборщик вызовет API Portals, если подключён публичный endpoint. На статической копии без API используйте слова поиска или URL Amazon.

Как добавить PickForge в Claude, ChatGPT или Grok?

Кнопки в блоке «Подключить ассистента» открывают настройки плагинов. Claude открывает Add custom connector с уже заполненными именем и адресом сервера. ChatGPT открывает Plugins: выберите Add custom MCP server и введите имя, описание и подключение с этой страницы. Grok открывает Connectors: New Connector, затем Custom. Подтвердите, прежде чем PickForge будет добавлен.
