# PickForge

> PickForge — инструмент поиска товаров для ИИ-ассистентов с помеченными партнёрскими ссылками. На странице есть сборка ссылки Amazon.com и раскрытие партнёрских отношений. PickForge ничего не продаёт.

## Поиск товаров с партнёрскими ссылками для ИИ-ассистентов

PickForge — инструмент, который ИИ-ассистент вызывает, когда вы просите найти товар. Он возвращает помеченную партнёрскую ссылку. На этой странице также собирается ссылка Amazon.com в вашем браузере. Платите магазину, не PickForge.

## Информационная страница сервиса в разработке

PickForge — независимый проект. Эта страница описывает сервис, то, как мы работаем с партнёрскими ссылками, и кто за ним стоит. Это не магазин, и мы ничего не продаём.

Ссылки Amazon.com на этой странице собираются в браузере: полный адрес amazon.com с идентификатором Associates pickforge-20. Партнёрскую ссылку AliExpress создаёт только API AliExpress Portals на нашем сервере. Эта страница не вызывает этот API и не подделывает ссылку.

Покупка проходит на сайте магазина, где видна цена. Мы не принимаем заказы, не храним товары и не даём финансовых или медицинских советов.

## Что делает инструмент

- **Поиск по запросу** (Поиск): Пользователь просит ИИ-ассистента подобрать тип товара или бюджет. Ассистент вызывает инструмент, который ищет подходящие позиции в партнёрских каталогах.
- **Партнёрские ссылки с пометкой** (Ссылки): Ссылка Amazon.com на этой странице — полный адрес с нашим идентификатором Associates. Партнёрскую ссылку AliExpress создаёт только официальный API Portals. Ссылка, которая может принести комиссию, помечена.
- **Не магазин** (Границы): Оформление заказа, оплата и аккаунты происходят на сайте продавца. Инструмент не принимает заказы и платежи.

## Принципы

- **Данные**: Поисковый запрос используется только для ответа на него. Мы не продаём персональные данные.
- **Комиссии**: Комиссия не меняет порядок результатов поиска. Ссылка, которая может принести комиссию, помечена.
- **Без заявлений о тестах**: Мы не заявляем о ручных тестах товаров. Информация о товарах берётся из данных продавцов и партнёрских программ.
- **Обновления**: Мы обновляем эту страницу, когда меняются сервис, партнёрские программы или раскрытие.

## Собрать ссылку магазина

Вставьте слова поиска, страницу товара Amazon или адрес товара AliExpress. PickForge сам определит магазин.

Слова поиска становятся ссылкой Amazon с tag=pickforge-20. Адреса Amazon и AliExpress распознаются автоматически.

## Партнёры

Поиск и помеченные партнёрские ссылки идут через эти программы. Оплата — на сайте магазина. Названия магазинов — торговые марки их владельцев.

- **Amazon** (Amazon Associates): Ссылки на товары и поиск на amazon.com с идентификатором Associates pickforge-20.
- **AliExpress** (AliExpress Portals): Партнёрские ссылки создаёт только официальный API Portals.

## Добавить инструмент в ассистент

Поиск товаров — это MCP-сервер: служба, которую ассистент вызывает, когда вы просите найти товар. Он возвращает ссылки. Ссылка, которая может принести комиссию, помечена. Платите магазину, не PickForge.

PickForge ещё нет в каталоге плагинов. Адрес сервера: https://pickforge-mcp.onrender.com/sse. Каждая ссылка открывает страницу добавления плагина. Имя, описание и подключение указаны на карточке. Ссылка Claude подставляет имя и адрес сервера. Подтвердите, прежде чем сервер будет добавлен. Не вставляйте адрес localhost.

- [Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=PickForge&connectorUrl=https%3A%2F%2Fpickforge-mcp.onrender.com%2Fsse): Открывает Add custom connector: имя и адрес сервера уже заполнены. Проверьте их и добавьте.
  - Имя: PickForge
  - Подключение: https://pickforge-mcp.onrender.com/sse
- [ChatGPT](https://chatgpt.com/plugins): Открывает ChatGPT Plugins. Выберите Add custom MCP server и введите имя, описание и подключение. Authentication: No authentication. Затем Create as a plugin.
  - Имя: PickForge
  - Описание: Поиск товаров с помеченными партнёрскими ссылками. Платите магазину, не PickForge.
  - Подключение: https://pickforge-mcp.onrender.com/sse
- [Инструкция ChatGPT](https://developers.openai.com/api/docs/guides/custom-mcp-server): Шаги OpenAI для своего MCP-сервера.
- [Grok](https://grok.com/connectors): Открывает коннекторы Grok. Выберите New Connector, затем Custom, и введите имя и адрес сервера.
  - Имя: PickForge
  - Подключение: https://pickforge-mcp.onrender.com/sse

## Раскрытие партнёрских отношений

PickForge участвует в Amazon Associates и в партнёрской программе AliExpress (Portals). Если вы купите товар по ссылке, которую мы пометили, мы можем получить комиссию. Доплаты нет.

Цены, наличие и условия меняются. Перед покупкой проверьте их на сайте магазина. Названия магазинов — товарные знаки владельцев.

Ссылки Amazon.com на этой странице — полный адрес amazon.com, включая идентификатор Associates pickforge-20. Мы не прячем его за коротким адресом. Amazon не спонсирует и не поддерживает PickForge. Ниже — обязательная формулировка программы на английском.

## Конфиденциальность

Эта страница статическая: без регистрации, формы обратной связи и рассылки.

Сборщик ссылок работает в вашем браузере. Адрес товара или слова поиска не отправляются в PickForge. Переход открывает Amazon или, если ссылку выдал наш сервер, AliExpress. Эти магазины могут ставить свои cookie.

Инструмент ассистента, когда он будет опубликован, получает поисковый запрос только чтобы вернуть результат. Мы не продаём персональные данные. Хостинг может записывать обычные данные доступа (IP-адрес, user agent).

## Вопросы

### Что такое PickForge?

Независимый проект: инструмент, с помощью которого ИИ-ассистенты ищут товары и возвращают партнёрские ссылки. Сервис в разработке.

### Вы продаёте товары?

Нет. Покупки совершаются на сайтах продавцов. Мы не ведём оформление заказов, не храним товары и не ведём аккаунты покупателей.

### Влияют ли комиссии на результаты?

Нет. Комиссия не меняет порядок результатов поиска.

### Помечены ли партнёрские ссылки?

Да. Ссылка, которая может принести комиссию, помечена как партнёрская.

### Можно ли собрать ссылку Amazon на этой странице?

Да. Сборщик возвращает полный адрес amazon.com с tag=pickforge-20. Откройте его с этой страницы. Цену страница не показывает.

### Можно ли собрать ссылку AliExpress на этой странице?

Вставьте URL товара AliExpress — сборщик вызовет API Portals, если подключён публичный endpoint. На статической копии без API используйте слова поиска или URL Amazon.

### Как добавить PickForge в Claude, ChatGPT или Grok?

Кнопки в блоке «Подключить ассистента» открывают настройки плагинов. Claude открывает Add custom connector с уже заполненными именем и адресом сервера. ChatGPT открывает Plugins: выберите Add custom MCP server и введите имя, описание и подключение с этой страницы. Grok открывает Connectors: New Connector, затем Custom. Подтвердите, прежде чем PickForge будет добавлен.

### Как связаться с издателем?

На этой странице нет формы обратной связи.
